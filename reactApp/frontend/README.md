# BrainCharge frontend

React (Vite) PWA for the BrainCharge companion web app.

**Full setup, auth, calendar, Nano face link, and API docs:** see the parent guide → [../README.md](../README.md).

## Quick start

```powershell
# Backend must be running first (see parent README)
cd reactApp/frontend
npm install
npm run dev
```

Open **http://localhost:5173**. Vite proxies `/api` to `http://127.0.0.1:3001`.
